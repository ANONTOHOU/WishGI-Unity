# 中期检查参考文献建议

以下两篇文献与本项目的技术路线相关度较高，但关注点分别放在低频漫反射光照表示和预计算光照传输上，适合用于说明本课题的技术基础并避免参考来源过于单一。

## 1. An Efficient Representation for Irradiance Environment Maps

- 作者：Ravi Ramamoorthi, Pat Hanrahan
- 会议：SIGGRAPH 2001
- 主要相关性：
  - 该文系统说明了漫反射环境光照可以用低阶球谐函数进行高效近似。
  - 文中给出了只使用前 9 个球谐系数即可较好表示低频漫反射光照的理论和实验依据。
  - 本项目在运行时采用低阶球谐重建间接光照，与该文在低频漫反射表示方面高度相关。
- 可用于论文中的表述方向：
  - 说明球谐表示并非单一项目特有，而是计算机图形学中较成熟的低频光照表示方法。

推荐引用格式：

Ramamoorthi, R., Hanrahan, P. An Efficient Representation for Irradiance Environment Maps. In Proceedings of SIGGRAPH 2001, 497-500.

参考页面：
[graphics.stanford.edu/papers/envmap](https://graphics.stanford.edu/papers/envmap/)

## 2. Precomputed Radiance Transfer for Real-Time Rendering in Dynamic, Low-Frequency Lighting Environments

- 作者：Peter-Pike Sloan, Jan Kautz, John Snyder
- 会议：SIGGRAPH 2002
- 主要相关性：
  - 该文提出了预计算光照传输的代表性思路，将复杂光照影响预处理后在运行时快速重建。
  - 文中使用低频基函数和预计算数据支持实时渲染，与本项目“离线计算 + 运行时重建”的总体路线高度接近。
  - 虽然本项目的具体工程结构、数据组织和 Unity 接入流程是自行设计实现的，但在“预计算 + 压缩表示 + 实时恢复”这一思路上与该文有较强关联。
- 可用于论文中的表述方向：
  - 说明本课题的整体技术路线与图形学中经典的预计算实时光照方法具有继承关系，而不是仅依赖单一近年工作。

推荐引用格式：

Sloan, P.-P., Kautz, J., Snyder, J. Precomputed Radiance Transfer for Real-Time Rendering in Dynamic, Low-Frequency Lighting Environments. ACM Transactions on Graphics, 21(3), 2002, 527-536.

## 使用建议

在中期检查、开题答辩或论文相关章节中，可以将这两篇文献与本项目当前参考的其他工作并列呈现，形成如下表述逻辑：

1. 低频漫反射光照可由球谐函数高效表达。
2. 复杂光照传输可以通过离线预计算降低运行时开销。
3. 本课题在此基础上，结合 Unity 工程环境，完成了面向静态场景的离线烘焙、数据打包和运行时重建流程设计。

这样的写法可以有效避免材料中对单一文献的依赖显得过重，同时也更符合毕业设计中“综合调研后自主实现”的表达方式。
