## 中文摘要

针对移动端与中低端图形硬件在静态全局光照应用中面临的运行时开销高、内存占用大和工程接入复杂等问题，本文完成了一套基于球谐函数拟合（Spherical Harmonics, SH）的轻量级静态全局光照烘焙系统。系统以 WishGI 思路为参考，围绕“可落地实现”和“可复现效果”开展设计：离线阶段依次完成表面采样与路径追踪、探针分布与权重估计、SH 系数拟合与 ProbeMap 打包；运行时阶段在 Unity URP 中通过 uv2 顶点关联与法线方向重建间接光贡献。本文重点不是仅给出理论模型，而是将算法链路完整工程化，形成可执行脚本、统一数据格式与编辑器工具流程。

在实验中，本文采用二阶 SH（9 基函数）、128 个 probe、960 个半球方向采样，完成端到端实跑。结果显示，流程可稳定输出各阶段产物：采样阶段获得 1024 个有效样本；拟合阶段生成 probes_sh.npy，形状为 (128, 9, 3)；打包阶段生成 probe_map.npy，形状为 (1, 896, 4)，且无 NaN/Inf 异常。通过产物一致性和运行时回放验证，本文系统满足“低频静态 GI 重建可用、工程流程清晰、参数可调可复现”的目标。本文还对局限性进行了分析，包括高频阴影表达不足、动态物体支持不完整、按 mesh 独立探针资源尚未自动化等，并给出后续改进方向。

关键词：静态全局光照；球谐函数；探针烘焙；Unity URP；离线拟合

## 英文摘要

To address high runtime cost and memory overhead of static global illumination on mobile and low-end devices, this thesis implements a lightweight static GI baking system based on spherical harmonics fitting. The work focuses on practical realization rather than pure theory derivation. The complete pipeline includes offline surface sampling and path tracing, probe distribution and weight estimation, SH fitting, and ProbeMap packing, followed by runtime reconstruction in Unity URP using vertex association data in uv2.

In the end-to-end experiment, SH order 2, 128 probes, and 960 hemisphere directions were used. The pipeline finished successfully and produced consistent artifacts: 1024 effective samples, probes_sh.npy with shape (128, 9, 3), and probe_map.npy with shape (1, 896, 4), with no NaN/Inf failures. The results demonstrate that the system is reproducible and suitable for low-frequency static GI reconstruction under constrained hardware budgets. Limitations and future improvements are also discussed.

Key words: Static Global Illumination; Spherical Harmonics; Probe Baking; Unity URP; Offline Fitting

# 第1章 绪论

## 1.1 研究背景与意义

全局光照（Global Illumination, GI）通过统一建模直接光和间接光，可以显著提升场景的真实感、空间层次感以及材质表现一致性。对于游戏与实时可视化而言，GI 的价值不仅在于“更亮或更暗”，更在于光能在多次反射后与几何结构共同作用产生的色彩溢出、遮蔽过渡与体积感。然而，在移动端与中低端平台中，算力和带宽预算有限，常见高质量 GI 方案难以直接部署：一类方案高度依赖像素级纹理采样，另一类方案需要额外渲染通道与较大体积数据，均会带来帧时间和内存峰值压力。

在这种约束下，静态场景的离线烘焙路线具有明显优势。其核心思想是将高成本计算转移到离线阶段，运行时仅保留低复杂度重建。该思想并非新提出，但在工程实践中常出现三个问题：第一，离线和运行时的模型不一致导致“能拟合、难还原”；第二，数据格式跨工具链流动时易出现字段不匹配与数值异常；第三，研究论文中的方法缺少可执行脚本与面向引擎的完整落地。上述问题正是毕业设计中最常见的“理论可行而效果不稳定”的根源。

因此，本文的研究意义在于把论文方法“做成系统”而非“写成概念”。具体体现为：在 Python 离线流程中构建可复现、可参数化、可校验的处理链路；在 Unity URP 中构建导入与重建闭环；在实验章节用端到端实跑结果验证流程可用性。该工作可为后续课程设计、毕业设计和实际项目提供一套模板化的轻量 GI 工程范式。

## 1.2 国内外研究现状

从工业实践看，静态光照方案大致可分为 Lightmap 路线、探针路线和混合路线。Lightmap 路线运行时成本低，但依赖 UV 展开质量、贴图分辨率与压缩策略，在低分辨率下容易出现接缝、糊化和块状误差。探针路线以空间离散点表示照明，适合动态取样与共享资源，但在运行时通常需要多探针插值和较大纹理带宽，若数据组织不合理，同样会造成性能压力。

球谐函数（SH）由于具备低频表达能力和线性可加性，被广泛用于环境光近似与探针重建。二阶 SH 仅需 9 个基函数即可表示低频漫反射主成分，配合少量探针即可在移动端达到“可用质量”。WishGI 类方法进一步强调“顶点关联 + 运行时轻采样”的思路，通过离线拟合将复杂度转移，适合前向渲染和资源受限平台。本文即在这一方向上完成工程实现，并针对可复现性与鲁棒性做补强。

## 1.3 研究内容与技术路线

本文围绕“效果实现”组织工作，技术路线如下：
1. 从场景网格与光源出发，构建离线采样数据。
2. 通过 K-Medoids 在样本空间分布 probe，并生成 sample/vertex 权重。
3. 用加权最小二乘求解 probe 的 SH 系数，输出可打包数据。
4. 将系数打包为 ProbeMap 并导入 Unity，配合 uv2 完成运行时重建。
5. 通过端到端实跑与数值校验证明流程稳定性。

## 1.4 主要贡献

本文主要贡献可归纳为以下四点：
1. 实现了完整可执行的离线-运行时闭环，而非单点脚本验证。
2. 修复了多个影响稳定性的关键问题，包括基函数一致性、边界参数越界、病态方程求解失败等。
3. 完成了 128 probe 参数下的端到端实跑与产物一致性验证。
4. 形成了可直接迁移到 Word 的论文结构草案，便于后续定稿与答辩材料联动。

# 第3章 核心方法与数学建模

## 3.1 球谐光照重建模型

本文使用二阶实数 SH 近似漫反射间接光。对于任意表面点 p，其重建照明可写为 probe 线性组合后与 SH 基函数内积：

$$
\hat{L}(p, d)=\sum_{k=1}^{K} w_k(p) \sum_{i=1}^{9} c_{k,i} \phi_i(d)
	ag{3.1}
$$

其中，$w_k(p)$ 为点 p 对第 k 个 probe 的权重，$c_{k,i}$ 为第 k 个 probe 的第 i 个 SH 系数，$\phi_i(d)$ 为方向 d 上的 SH 基函数。该表达式体现了“空间低维关联 + 方向低频表示”的分解思想。

## 3.2 采样与方向权重建模

对每个采样点，以半球方向集 $\Omega$ 估计辐亮度观测值。考虑漫反射贡献主要集中在法线同侧，引入有效方向权重：

$$
w(d, n)=\max(0, d \cdot n)
	ag{3.2}
$$

则加权误差目标可写为：

$$
E_{light}=\sum_{p\in S}\sum_{d\in \Omega} w(d,n_p)\left(\hat{L}(p,d)-L(p,d)\right)^2
	ag{3.3}
$$

式（3.3）使拟合过程更加关注几何法线邻域，能够在同等方向数下提高视觉有效信息利用率。

## 3.3 探针分布与权重估计

### 3.3.1 K-Medoids 探针分布

设采样点集合为 $P=\{p_i\}$，目标是找到 K 个代表点（medoids）最小化簇内距离和：

$$
E_{cluster}=\sum_{j=1}^{K}\sum_{p\in C_j} dist(p, o_j)
	ag{3.4}
$$

其中 $o_j$ 为第 j 个 medoid，$C_j$ 为其对应簇。相比 K-Means，K-Medoids 代表点落在真实样本上，更符合几何语义。

### 3.3.2 稀疏权重构建

对每个样本点，仅保留 top-k 最近 probe 并做逆距离归一：

$$
	ilde{w}_{i,j}=\frac{1}{dist(p_i,o_j)+\epsilon},\quad
w_{i,j}=\frac{\tilde{w}_{i,j}}{\sum_{j\in TopK(i)}\tilde{w}_{i,j}}
	ag{3.5}
$$

该设计兼顾局部性和计算效率。样本权重用于拟合，顶点权重用于运行时 uv2 重建。

## 3.4 SH 拟合与正则化求解

将所有样本-方向观测展开后，可构建设计矩阵 A 与目标向量 b，转化为线性回归问题。加入岭正则得到：

$$
\min_x\ \|Ax-b\|_2^2+\lambda\|x\|_2^2
	ag{3.6}
$$

其正规方程为：

$$
(A^TA+\lambda I)x=A^Tb
	ag{3.7}
$$

本项目使用 $\lambda=0.1$。当 $A^TA$ 近奇异时，工程实现回退到最小二乘解，提升鲁棒性。

## 3.5 运行时重建与复杂度分析

运行时每像素从 uv2 解码两个 probe 索引 $(i_0, i_1)$ 与权重 $(\alpha,\beta)$，再做线性组合：

$$
c_i(p)=\alpha c_{i_0,i}+\beta c_{i_1,i},\quad i=1,...,9
	ag{3.8}
$$

然后对法线方向评估 SH。二阶 SH 下每 probe 27 浮点，打包后 7 texel/probe。该复杂度在移动端可接受。

# 第4章 系统实现

1. 解析多 mesh 三角面并构建 BVH。
2. 按最小距离约束进行表面蓝噪声采样。
3. 对每样本在预设方向集上进行辐亮度估计。

## 4.3 SH 拟合与打包模块实现

打包模块将 (P, 9, 3) 系数重排到 (1, width, 4) 纹理，其中 width=P*7。为防止文件路径仅文件名导致目录创建失败，脚本对输出路径进行了健壮性处理。

## 4.4 Unity 导入与运行时 Shader 实现

Unity 侧包含两个核心能力：
1. ProbeMap 导入：读取 npy 与 meta，创建 RGBAFloat 纹理资产。
2. Mesh 关联写入：读取 mesh_assoc，将 probe 索引和权重编码到 uv2。

运行时 Shader 根据 uv2 解码索引并采样 ProbeMap，重建法线方向 GI。本文将默认 probeCount 参数更新为 128，以匹配离线流程，减少人工配置错误。

## 4.5 工程健壮性修复与调试记录

围绕“系统可跑通”，本文对以下关键问题进行了修复：
1. SH 基函数一致性问题：离线与 Shader 常数不一致会造成偏色与亮度偏差，已统一。

4. 输出路径边界问题：防止空目录创建异常。
5. 默认参数偏离问题：拟合正则权重对齐到 0.1。

| top-k 越界 | 导出崩溃 | 参数钳制 | 可容错 |
| 空路径写文件 | 打包失败 | 条件创建目录 | 正常输出 |

## 5.5 消融与误差来源分析

为更清晰地说明“效果实现”的关键因子，本文从工程角度进行误差来源分析：

1. 采样误差：采样点密度不足会导致局部照明不稳定。
2. 方向离散误差：方向数较低时拟合偏差增大。
3. 分布误差：probe 数过少会导致跨区域表达不足。
4. 拟合误差：正则参数过小或过大会影响细节与稳定性的平衡。
5. 重建误差：离线与运行时基函数常数不一致会产生系统性偏差。

基于上述分析，本文优先保证一致性与稳定性，再逐步提高质量参数，形成“先跑通、后优化”的工程策略。

# 第6章 结论与展望

## 6.1 工作总结

本文围绕静态 GI 轻量化实现完成了从离线算法到 Unity 运行时的完整链路建设。与仅做理论推导不同，本文重点解决了工程落地中的一致性问题、数据接口问题和稳定性问题，并通过端到端实跑给出可复现证据。主实验在 128 probe、960 方向参数下稳定完成，证明方案可用于静态场景的低频间接光重建。

## 6.2 不足分析

当前方案仍存在以下不足：
1. 对动态物体支持有限，仍以静态对象为主。
2. 高频光照细节受二阶 SH 限制，边缘锐度不足。
3. 尚未形成按 mesh 自动分桶输出 probemap 的批处理流程。
4. 指标层面目前以工程可执行和维度一致性为主，主观图像与客观 mRMSE 对照仍可加强。

## 6.3 后续研究方向

后续可从四个方向推进：
1. 多 mesh 独立 probemap 自动化输出与资源管理。
2. 结合可见性图与测地距离优化探针分布，降低漏光。
3. 引入多时段 probemap 插值，支持低成本昼夜变化。
4. 增加对比基线实验（lightmap、体积探针）与更系统的定量评估。
