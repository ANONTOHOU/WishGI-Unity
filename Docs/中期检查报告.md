# 中期检查报告

## 一、课题名称

基于 Unity 的轻量化静态全局光照烘焙与重建系统设计与实现

## 二、课题研究目的与意义

本课题围绕三维场景中的静态全局光照问题展开，目标是在 Unity 环境下设计并实现一套兼顾画质、性能和工程可用性的轻量化全局光照方案。传统实时全局光照方法虽然效果较好，但通常对硬件性能要求较高，在移动端或资源受限平台中应用存在一定限制。针对这一问题，本课题采用离线预处理与运行时快速重建相结合的思路，将复杂的光照计算前置到离线阶段完成，在运行时通过较小的数据规模和较低的采样开销恢复场景中的间接光照效果。

课题的意义主要体现在两个方面。其一，从技术实现角度看，本课题尝试将静态光照采样、探针分布、方向光照压缩、数据打包和引擎侧导入重建等环节串联起来，形成完整的工程流程，而不是停留在单一算法验证层面。其二，从应用价值角度看，该系统适用于对实时性能较敏感、但仍需要一定全局光照质量的场景，对于中小型项目、教学演示和图形学原型验证具有一定参考价值。

## 三、课题主要研究内容

本课题的主要研究内容包括以下几个部分：

1. 场景网格表面采样与光照数据生成。针对输入网格模型，在其表面进行采样，并结合路径追踪方法获得采样点在多个方向上的辐亮度信息，为后续压缩与拟合提供基础数据。
2. Probe 分布与关联关系构建。根据场景中的采样点分布生成数量可控的 Probe，并建立采样点到 Probe、顶点到 Probe 的权重映射关系，用于后续的光照压缩和运行时插值。
3. 方向光照压缩与参数拟合。利用球谐函数对多方向光照进行低维表示，通过带正则项的最小二乘方法求得每个 Probe 的系数表达，以减小数据规模。
4. 数据打包与 Unity 运行时接入。将离线求得的 Probe 系数打包为适合运行时读取的纹理数据，同时在 Unity 端实现导入工具、顶点通道写入和着色器解码，以完成静态全局光照的实时重建。
5. 系统联调与工程优化。围绕离线与运行时一致性、Probe 分布稳定性和导入流程鲁棒性等问题，对整体系统进行联调与修正，提升原型系统的可运行性和可复现性。

## 四、目前已完成的工作

截至中期检查阶段，课题已经完成了系统主体流程的搭建和主要模块的实现。

在离线部分，已经完成网格表面采样模块与基础路径追踪模块，可以输出采样点的位置、法线、方向集以及每个方向上的辐亮度数据。围绕采样结果，已经完成 Probe 分布模块和权重导出模块，能够根据场景中的采样点生成 Probe 位置，并建立采样点到 Probe、网格顶点到 Probe 的稀疏权重关系。

在光照压缩部分，已经实现球谐基函数计算、带正则项的系数拟合以及 Probe 数据打包流程，可将离线计算结果压缩为适合 Unity 侧读取的纹理化数据结构。在运行时部分，已经完成 Unity Editor 工具的开发，包括 Probe 纹理导入、关联数据写入模型 uv2 通道等功能；同时已经完成基础 Shader，实现了根据顶点关联权重对 Probe 数据进行解码并重建静态 GI 的显示流程。

从系统整体状态来看，目前已经形成了从离线预处理到 Unity 场景显示的完整闭环，具备了可运行的原型系统和示例场景验证能力。

## 五、阶段性成果与问题分析

在实现过程中，已经取得以下阶段性成果：

1. 初步打通了离线采样、Probe 生成、系数拟合、数据打包和 Unity 导入的完整流程。
2. 建立了较清晰的数据组织方式，能够输出 samples、probes、权重矩阵和纹理化 Probe 数据等中间结果，便于调试和后续实验。
3. 在 Unity 中实现了对应的编辑器工具和运行时 Shader，验证了整体方案具备工程落地的可行性。

与此同时，项目实现过程中也暴露出若干问题。

首先，离线拟合与运行时着色器恢复之间曾出现结果不一致的问题。针对这一问题，重新检查了方向采样权重、法线余弦衰减、球谐基函数和着色器端解码逻辑，统一了离线与运行时的计算方式，从而改善了最终显示效果。

其次，Probe 分布策略在早期实现中存在落点不够稳定的问题，部分结果难以较好贴合有效表面区域，影响后续权重分配质量。针对这一问题，对 Probe 生成方法进行了调整，使得 Probe 布局更加符合实际采样点空间分布。

再次，在 Unity 导入流程中，还遇到了路径推断不完整、Probe 数量识别异常和命令格式不稳定等工程问题。通过补充元数据校验、改进路径推断逻辑和规范化执行命令，系统整体稳定性已有明显提升。
